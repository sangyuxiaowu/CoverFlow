# 旧项目兼容与转换

旧 `.cfj` 项目仍可读取，保存时使用 `.cfjx`，不会覆盖旧文件。10.0.0 将移除旧格式兼容，请在升级前转换。旧单 JSON `.cfjx` 需通过转换脚本拆分后才能打开；SVG 和 HTML 内部内容保持原样。

浏览器 IndexedDB 中的旧内嵌图片会在打开项目时迁移。文件夹存储中同 ID 的新旧项目只显示一次，优先使用 `.cfjx`；在项目库删除该项目会删除对应的两种文件。

## 转换项目文件

转换需要安装 Bun 并在项目目录运行。脚本支持指定单个文件或目录；处理目录时只扫描该目录下的 `.cfj` 和 `.cfjx` 文件，不递归子目录。建议先备份原文件、试运行，再确认输出：

```powershell
bun run convert:cfj "F:\CoverFlow\data" --dry-run
bun run convert:cfj "F:\CoverFlow\data" --output "F:\CoverFlow-converted"
```

不指定 `--output` 时，转换结果写入原文件所在目录。旧 `.cfj` 输出为同名 `.cfjx`，旧单 JSON `.cfjx` 输出以 `.converted.cfjx` 结尾；新版 `.cfjx` 会跳过。脚本不覆盖或删除原文件，也不会覆盖已存在的目标文件。

脚本会校验读取及打包往返，实际写入时还会验证临时文件；目标文件通过同目录临时文件和硬链接创建，目标文件系统需支持硬链接。CFJX 限制压缩包不超过 256 MiB、单张图片不超过 64 MiB、展开总量不超过 512 MiB。遇到损坏、超限或目标已存在的文件会报错并继续处理其他文件；请检查最终失败数量。
