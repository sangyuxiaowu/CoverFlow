## AI 接入点可能受服务端 CORS 配置影响

**状态：待处理**

部分模型服务商或自建兼容接口的跨域资源共享（CORS）配置可能不允许 CoverFlow 所在来源发起浏览器请求，导致 AI 接入点无法正常调用。此时浏览器开发者工具中可能出现 CORS 错误，请求也可能在到达模型服务前被拦截。

排查时需确认服务端允许应用来源跨域访问，并允许请求使用的 HTTP 方法及请求头。该问题可能由服务端配置引起，不一定是接入点地址、密钥或模型配置错误。

## Tauri 模式暂不支持屏幕取色

**状态：待处理**

屏幕取色依赖浏览器 `EyeDropper` API，但 Tauri 使用的 WebView 不提供该 API，因此 Tauri 模式下的吸管按钮目前禁用。浏览器中是否可用取决于浏览器对该 API 的支持。

后续可评估原生取色能力，再决定是否恢复 Tauri 模式下的吸管按钮。考虑先改为应用内取色功能。
